Integrasi AI

Status: template lokal — AI belum aktif
Ringkasan & judul otomatisDisiapkan untuk API backend

Tombol di bawah memakai backend proxy kalau sudah dikonfigurasi (AI_CONFIG.endpoint). Selama belum aktif, hasilnya memakai template lokal dari berita terpilih — dilabeli [Template], bukan hasil AI. API key disimpan di server dan tidak pernah disimpan di frontend atau di file ini.

AI memakai berita pertama dari kategori yang sedang aktif. Tekan salah satu tombol di atas. Hasil tampil di sini.

Kontrak proxy: POST ke endpoint dengan JSON {task: "summary"|"title"|"caption"|"translate", text: "..."} → balas JSON {result: "..."}. Aktifkan dengan mengisi AI_CONFIG.endpoint di file ini (tanpa API key).

AI_CONFIG = { enabled: false, provider: null, endpoint: '' } // Ringkasan otomatis + judul/caption via backend proxy. // Frontend tidak menyimpan API key.
